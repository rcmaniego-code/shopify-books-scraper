# Shopify Book Scraper

A Python scraper that extracts book data from books.toscrape.com and converts it to Shopify-ready CSV/XLSX.

### ✅ Features:
- Scrapes Title, Price, Availability, Image URL
- Auto-generates Shopify Handles
- Outputs styled .xlsx with blue header
- Ready for Shopify Bulk Import

### 🛠️ How to Run:
1. `pip install pandas xlsxwriter requests beautifulsoup4`
2. `python shopify_scraper_pro.py`
3. Import the generated CSV to Shopify

Demo Site Used: books.toscrape.com
